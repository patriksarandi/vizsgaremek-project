This project is a final exam project completed as part of the School program. 
The application offers a modern solution for managing an online webshop store.

📋 Key Features
Authentication: JWT-based registration and login with secure password storage.
CRUD module: Create, read, update, and delete data.
Search and filtering: Fast, real-time search functionality within the data.
Admin interface: Separate permission levels for data management.
Responsive UI: Fully optimized for mobile and tablet devices.

🛠 Technology stack
Frontend
Framework: React
Styling: Bootstrap
Backend & Database
Runtime: Node.js
Database: MySQL

ORM/Query Builder: Prisma

🚀 Installation and usage
Cloning the repo:

Bash
git clone https://github.com/patriksarandi/vizsgaremek-project.git
cd vizsgaremek-project

Start the server:

Bash
cd backend
npm install
# Create a .env file with database credentials
npm start
Start the client:

Bash
cd frontend
npm install
npm run dev

📂 Project structure
/backend – API endpoints, database schema, and business logic.
/frontend – User interface components and services.
